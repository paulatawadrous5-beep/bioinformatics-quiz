# Bioinformatics Quiz Simulator

## Included
- Top 25: curated high-priority questions
- Top 50: curated high-priority questions
- All Questions: 80 questions with answer keys printed in the PDF + 17 questions whose answer keys were absent from the PDF
- Randomized question order and randomized answer choice order on every attempt
- Percentage score, correct/incorrect counts, answer review
- Retry incorrect questions or retry the full selected set

## Important answer-key note
The source PDF does not print answers for 17 multiple-choice questions in its third section. Those questions are included only in All Questions and use provisional answer keys based on the question wording and study content. They are visibly labeled in the app. Top 25 and Top 50 use only the 80 questions with answers printed in the PDF.

## Deploy to Vercel
1. Extract the ZIP.
2. Open https://vercel.com/new
3. Choose **Deploy** / **Import** or drag the extracted folder into Vercel if prompted.
4. For this static site, no build command or environment variables are required. Set the framework preset to **Other** if Vercel asks.
5. After deployment, copy the public `.vercel.app` URL and send it to your friend.

You can also deploy by importing a GitHub repository containing `index.html`.
